# Aturan Project QA Automation Hadir

## Konteks Project
Project akhir QA Automation untuk Hadir Web sisi HRD.

URL:
https://magang.dikahadir.com/authentication/login

Teknologi:
- Java
- Selenium WebDriver
- TestNG
- Maven

## Aturan Kerja
1. Gunakan bahasa Indonesia untuk semua penjelasan.
2. Jelaskan setiap langkah agar saya memahami prosesnya.
3. Sebelum membuat atau mengubah file, tampilkan rencana dan tunggu persetujuan saya.
4. Kerjakan project secara bertahap, jangan sekaligus.
5. Jangan mengarang locator, kredensial, atau expected result.
6. Gunakan requirement sebagai dasar pembuatan test case.
7. Gunakan Page Object Model untuk struktur automation.
8. Gunakan explicit wait jika diperlukan.
9. Hindari Thread.sleep tanpa alasan yang jelas.
10. Gunakan assertion TestNG untuk validasi hasil.
11. Jangan melakukan perubahan data website tanpa izin.
12. Jelaskan penyebab error sebelum memperbaikinya.
13. Jangan menyatakan test PASS sebelum benar-benar dijalankan.

## Tahapan Pengerjaan
1. Setup Maven dan dependency.
2. Identifikasi elemen halaman login HRD.
3. Susun test scenario dan test case.
4. Buat automation script Selenium.
5. Jalankan test menggunakan TestNG.
6. Buat test report dan evidence.

## Fokus Saat Ini
Periksa environment dan rencanakan struktur project Maven.
Jangan membuat file project lainnya sebelum mendapat persetujuan.
